# Presentation

This directory contains the final 15-slide defense presentation as a PDF.

- [Presentation PDF](DEIM-presentation.pdf)
- [Interactive web presentation](https://m8tko.github.io/Masters-Thesis-DEIM/)

The interactive version supports arrow-key navigation, `S` to return to the first
slide, `P` to play or pause video, and `F` for full screen.

The Beamer working source and oral-exam notes are intentionally excluded from the
public repository.
